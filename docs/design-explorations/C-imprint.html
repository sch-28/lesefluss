§ 01 · about

A reading app for books,
web novels, and pasted URLs.

Lesefluss reads EPUBs, PDFs, HTML, plain text, or any URL. RSVP mode shows one word at a time — many people read 2–4× faster. Free, open source, offline-capable.

$ lesefluss --help

read books · web novels · any URL

modes: pages | scroll | rsvp

themes: light | dark | sepia

price: free

$ open web app $ get on android $ git clone

§ 02 · read

Three modes.#

Pages, scroll, or one word at a time. Switch any time — position and highlights persist.

// pages

Lorem ipsum dolor sit amet consectetur. Sed do eiusmod tempor incididunt ut labore.

← →

// scroll

Lorem ipsum dolor. Sed do eiusmod. Ut enim ad. Duis aute irure.

↕

// rsvp

patience

⏵ 600wpm

What is RSVP?#

Rapid Serial Visual Presentation. One word at a time, anchored on a focal letter. Eyes don't have to jump back to re-read.

// example
word: "patience"
focal: 2 // the 'a'
wpm: 600
pause_after: { comma: 120, period: 240 }

§ 04 · reader features

Small dials.#

  • · themes  — light, dark, sepia
  • · typography — font, line-height, margins, app size
  • · speed    — wpm, pauses, acceleration, focal offset
  • · highlights — tap word → definition; colored swatches
  • · glossary  — per-book; names/places light up in text
  • · auto-advance — next chapter rolls in, pre-fetched
  • · offline   — everything works without a connection
  • · sync     — optional · google/discord/email
